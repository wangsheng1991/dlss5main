# DLSS5 × AIGC × 游戏：改人物、改服装、迭代修改（2026-11-26）

## 一句话

**DLSS5 管「像不像这个游戏」，AIGC 管「这个人是谁」。** 两者不是并列的两个功能，是一条流水线的前后两段：先增强输入，再改内容，最后修复接缝。

单做换脸 → 糊、穿帮、和场景光照打架。
单做超分 → 清楚，但画面里还是原来那个人。
合起来才成立。

## 「实时」其实是三个产品

用户说的「实时修改」，拆开是三种完全不同的东西，成本和风险差一个数量级：

| 等级 | 形态 | 延迟预算 | 能不能做 | 风险 |
| --- | --- | --- | --- | --- |
| **A 截图级** | 游戏里按暂停/截图 → 改脸改衣 → 出图 | 1–3 秒，可接受 | **现在就能做** | 几乎没有 |
| **B 回放级** | 录一段 10–30 秒 → 处理 → 出视频 | 分钟级 | 已有管线（见 `video-face-swap`） | 低 |
| **C 准实时** | 边玩边处理，画面延迟几百毫秒 | 100–300 ms | 技术上勉强，体验有瑕疵 | 中 |
| **D 真实时** | 60fps 内改完 | < 16 ms | **单卡做不到**，要引擎内集成或云端串流 | 高 |

**关键判断：用户要的不是 60fps，是「我改一下，马上看到」。** A 级的 1–2 秒已经满足这个心理需求，而且它是唯一能立刻上线、零封号风险的形态。

真要做 D，只有两条路：游戏引擎内挂后处理（要厂商配合），或云游戏串流（成本高、延迟叠加）。**不要在这上面先投入。**

## 流水线怎么接

```
游戏画面
  ↓ ① 截取（A 级：截图；C 级：DXGI/ReShade hook）
  ↓ ② 人物分割（把人从背景里抠出来，只需 10–30 ms）
  ↓ ③ DLSS5 预增强（低清/噪点 → 干净底图，给 AIGC 一个好输入）
  ↓ ④ AIGC 改内容（换脸 / 换装 / 改风格，2–8 s）
  ↓ ⑤ DLSS5 后修复（接缝、边缘、光照统一，0.5–1 s）
  ↓ ⑥ 合成回原画面（保留 UI、保留背景）
最终画面
```

**③ 和 ⑤ 是 DLSS5 真正的价值位**：不是「让游戏更清楚」，是「让 AI 改过的地方看起来像游戏本身」。第 ⑤ 步做不好，用户一眼就看出哪块是 P 的。

## 脸和服装是两件事

| | 换脸 | 换装 |
| --- | --- | --- |
| 技术 | inswapper 系，成熟 | 虚拟试衣 / inpaint 重绘，半成熟 |
| 难点 | 角度、遮挡、多人 | 全身、遮挡、物理、风格一致 |
| 现状 | 概率成功，重跑常能对 | 需要参考服装图，成功率更低 |
| 建议 | **先做脸** | 第二阶段 |

游戏角色更麻烦：多数不是真人脸，写实模型套上去会进恐怖谷——这是审美问题，修不好，只能靠风格化模型或只做「真人化」这个方向。

## 最大的风险不是技术

1. **反作弊**：任何 hook 游戏进程 / 改渲染管线的做法，在联机游戏里等于自寻封号。**只做单人游戏、只做截图/录屏后处理，不碰进程内存。**
2. **版权**：改游戏内角色外观用于商业宣传，涉及游戏 IP。自用没问题，对外卖服务要说清楚。
3. **肖像**：用别人的脸要授权；用自己脸自用没问题。
4. **承诺**：换脸是概率的，**永远不许说「脸一定保持」**。

## MVP 路径（按能落地的顺序）

**第一步：截图级改脸（1–2 天）**
- 素材：一段单人游戏的截图或 2 秒静帧。
- 流程：分割人物 → 换脸 → 后修复 → 合成。
- 产出：一组 before/after，用 `skills/visual-compare` 的拖拽组件展示。
- 判据：用户能不能一眼看出「这是我，但穿在游戏里」。

**第二步：加换装**
- 需要一张参考服装图 + inpaint 模型。
- 判据：衣服的接缝、光照、褶皱是否可信。

**第三步：迭代式调整**
- 把「改一次」变成「调参循环」：换参考图、调强度、重跑，每次 1–2 秒。
- 这才是「实时」的正确形态——迭代快，不是帧率高。

**第四步（可选）：录屏/回放的准实时**
- 只处理人物区域的小图，异步补帧，做到 10–15fps 的「直播感」。
- 明确标注「准实时，非 60fps」。

## 商业落点

- **游戏角色写真**：截图级，卖给「想看看自己在游戏里长什么样」的人。
- **主播换脸**：准实时，卖订阅。
- **游戏 mod 设计**：改一次，导出贴图/模型，卖给 mod 作者。

优先做第一个：零风险、能立刻验证需求、且正好用上 `visual-compare` 的展示。
