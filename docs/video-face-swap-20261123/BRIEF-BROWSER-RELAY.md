# 给 Codex 的浏览器任务：把技术问题发到飞书的 Windows 智能体

## 目标

用你的浏览器，在王胜已登录的飞书网页里，把一段技术问题发给「Windows远程服务器」这个机器人，并把它可能的回复原样贴回来。

## 步骤

1. 打开 `https://qianzhi-tech.feishu.cn/messenger/`。
   - 如果跳登录/扫码页：**立刻停下**，回一句「飞书未登录，需要王胜本人登录」。不要尝试扫码，不要输任何账号密码。
2. 在左侧会话列表里找名字是「Windows远程服务器」的会话（可能显示为「Windows远程服务器」或类似的机器人会话）。找不到就停下并说明你看到了哪些会话名。
3. 把下面这段原文发过去（**不要改字**，开头那行自报身份必须保留）：

```
【代发·来自王胜 Mac 上的 PenguinHarness 智能体，不是王胜本人】

王胜今天提了一个需求：把自己换到视频里当主角，用在游戏场景（游戏过场、角色自拍这类）。他要我先跟你确认那几台机器的家底，再决定做不做、怎么做。

背景：我这边是 Intel Mac，AMD 4GB 显存，跑不了任何换脸模型，所以只能在你那台和 250/251 井道上做。

按编号回就行，不用客套：

1. 你那台 Windows（DESKTOP-FG2GM17）的 GPU 型号和显存各是多少？
2. img3d 后面挂的 250 / 251 两条 GPU 井道，卡是什么型号、多少显存？有没有装 CUDA 和 PyTorch？版本多少？
3. 机器上现在有没有 ComfyUI、FaceFusion、或者现成的 Python 环境？能装吗（有没有外网）？
4. 能不能跑 24GB 级模型（比如 Wan-Animate 14B）？跑不动就老实说跑不动，我按跑不动来设计。
5. 磁盘剩多少、上传带宽大概多少、能不能对外提供下载链接？
6. 拿一段 10 秒 1080p 视频做换脸，大概要跑多久？（这个决定我怎么做报价）

另外两个判断题，你按经验说就行：

7. 游戏画面里第三人称、角色快速转身、带武器遮挡的镜头，换脸模型大概率会糊——你那边实际跑过的情况是不是这样？
8. 你觉得先做「只换脸」还是直接上「全身角色替换」？我的判断是先只换脸，全身那个太重。
```

4. 发送后等 2–3 分钟，再读该会话的最新消息。
   - 有回复：把回复原文完整贴回来（保留编号和换行）。
   - 没有回复：说明「已发出，暂无回复」，并贴出发送后会话里最后一条消息的时间和内容。

## 硬性约束

- 不要冒充王胜本人，消息里那行【代发·…】不能删。
- 不要往任何其他会话发消息；只发这一个。
- 不要改仓库里的任何文件，不要 git。
- 任何一步卡住（要登录、找不到会话、需要滑动验证），停下来说清楚卡在哪，不要反复重试。
- 完成后用中文回三行以内：发了没有、有没有回复、卡在哪一步。
