# 游客路径的丝滑与聚焦复核（2026-09-30）

本文件是产品负责人的要求，2026-09-30 转达。上一份相关文件是 `UX_CONVERT_FIRST_2026-09-27.md`：那份解决的是「第一眼看什么」，这一份解决的是「第一眼之后走得顺不顺、会不会被别的东西拽走」。功能可以继续变多，但**当前这一条路径必须是最好的那一条**。

## 背景（可核对的现状）

- 最高频的入口查询（以你手上的 Search Console 数据为准；若 2026-09-20 之后没有更新，用这三条）：`dlss 5 image converter`（点击最高：30 次点击 / 163 次展示，CTR 18.4%）、`dlss 5 visual enhancer`（曝光最大：595）、`dlss 5 download`（419）。它们分别落在 `/`、`/game-character-style`、`/download`。
- 2026-09-30 线上实测（1440×900、未登录、中文）：`/` 首屏 900px 之内，游客唯一能点的行动是 y=850 的「打开工作室 · 免费试用示例」——贴着视口底边，再往下就没有了；同一屏里还有 11 项导航和「登录 / 注册」。

## 要求

1. **按最高频关键词走一遍完整游客路径**：搜索结果 → 落地页 → 免费运行示例 → 结果页 → 对比 / 下载 / 下一步。用真实录屏或逐步截图留证，每步记下：要不要滚动、点了几下、有没有等待或空白、有没有回头路。
2. **丝滑优先**：黑屏、白屏、卡在「转换中」、点了没反应、跑完看不到结果——都算阻断，最先修。
3. **聚焦**：每个页面同一时刻只应有一个主行动。检查首屏有没有被工具入口、案例画廊、其它工具推广、公告、注册/付费引导抢走注意力；主行动如果不在首屏内，就往上提。
4. **功能彼此不打扰**：工具多不是问题，但（a）不能在同一屏并排堆两个同权重的主 CTA；（b）一个工具的运行状态、配额或登录态不能影响另一个工具或当前这条路径；（c）跳出去的工具/落地页要能一眼回到主路径。
5. **中英一致，窄屏（375×812）也检查一遍。**

## 边界（不要做）

- 不重做视觉设计，不删减工具、落地页、API 契约、sitemap 条目；只改层级、顺序、可点区域与文案。
- 不动 `/download` 的索取流程与付费链路；除非它们正好挡住这条游客路径——那就只做最小修复并单独说明。
- 不为过检查而改测试断言，不把失败项写成通过。
- 不提交 `dist/`、`node_modules/`、密钥或未跟踪素材。

## 验收

- `npx tsc --noEmit`、`npm test`、`npm run build` 全绿。
- 生产部署后，用真实页面复核最高频关键词指向的那几页：首屏之内即可看到并完成第一个行动。
- 把逐步证据、本轮修了什么、以及特意不做的事项，写回本文件。

- `src/pages/Home.tsx`：把人物风格转换免费入口提升为首屏唯一主 CTA；原卡片按钮降为同一路径的文字链接。
