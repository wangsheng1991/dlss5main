# 商业包装与获客计划 · 2026-11-22

问题：我们有图像/视频超分、插帧、风格重绘，即将有 3D 重建与纹理贴图；有商业包装、有价格优势。怎么包装、怎么获客、怎么产生收入。

先说结论：**卡点不是算法，也不是包装，是「卖的东西」和「来的人」不匹配，而且最强的算法还没有可售卖形态。**

两个事实由此成立：

1. **一半流量是「找 DLSS 5」的资讯/下载意图**，他们不会买修图或超分。站名、标题、180 条页面都建在 `DLSS 5` 这个词上，这个词现在属于 NVIDIA 的新闻热度，不属于我们的产品。
2. **真正有购买意图的人一天不到一个**：`/pricing` 28 天 20 次访问，`/register` 50 次。在这种量级上做转化率优化没有意义——先要有对的人，再谈包装。

同时，我们最强的东西**还没有可卖的形态**：

- `/video-upscaler` 自己写着：`The public workspace currently supports still-image enhancement … while the video provider adapter is being connected`；视频超分/插帧的 API、上传、报价、输出交付都没接通。
- `/api-catalog.json` 写着：`This catalog does not offer a standalone public developer API`。对一个「世界领先的算法」来说，这是把最高毛利的通道主动关掉了。
- 现有可卖的只有 9 个图像模型 + 积分（Pro $19 / 500 额度，Team $79 / 2000）。

## 2. 为什么现在收不到钱（四个错配）

| 错配 | 现状 | 后果 |
| --- | --- | --- |
| **人群** | 51% 流量找 DLSS 安装包 | 广告/内容成本换来的不是买家 |
| **商品** | 卖「积分 + 9 个模型」 | 用户不知道自己要买哪个模型；决策成本 > 支付意愿 |
| **价格单位** | 按月订阅、按积分扣 | 一次性任务（修一张老照片、放大一集短剧）没有对应价格 |
| **通道** | 只有 C 端自助 + 桌面端，**没有 API / 白标** | 世界级算法只能卖给会自己点按钮的散户 |

价格也不是优势：Replicate 上 Real-ESRGAN 的零售价是 **$0.002/张**（$2/1000 张）。在通用超分上拼价格等于把自己归到免费开源那一档；而我们的 Pro 是 $0.038/张（$19 ÷ 500），是那档的 19 倍——所以真正的问题是**凭什么值这个价**，而不是还能不能更便宜。

## 3. 包装：三条产品线，各有自己的价格单位

不要卖「积分」，卖**工作结果**。同一套算法，三种卖法：

### 线 A · 任务型（C 端，一次性定价）
一次上传、一个结果、一次付款，不要注册漏斗挡在前面。

| SKU | 卖什么 | 建议价 | 锚点 |
| --- | --- | --- | --- |
| 老照片修复（单张） | 划痕/褪色/低分辨率 → 可打印 | $4.9 / 张，$14.9 / 5 张 | Topaz Photo $39/月 |
| 视频修复·短片段（≤60 秒） | 老录像/压缩片 → 1080p 成片 | $9.9 / 条 | Topaz Web Video $29/月 |
| 商品图去背/精修（批量 20 张） | 直接进店铺 | $9.9 / 20 张 | 通用按张零售远高于此 |
| 证件照（已有 `/tools/passport-photo`） | 合规尺寸 + 回执 | $2.9 / 套 | 线下相馆 ¥30–60 |

要点：结果页先给**带水印预览**，付款后给无水印原图/原片；退款条款写清楚（算法失败自动退）。这一条线的作用不是利润，是**拿到第一批真实付过款的人**，以及他们对价格的反馈。

### 线 B · 专业订阅（创作者/工作室）
把「一堆工具」变成「一条流水线」：批量、队列、4K/60、保留元数据、API 额度。

| 档 | 内容 | 建议价 | 锚点 |
| --- | --- | --- | --- |
| Free | 10 张/天、带水印、3 次生成 | $0 | 现有 |
| Creator | 图像不限量（合理使用）+ 10 分钟视频/月 + 批量桌面端 | $19/月 | Topaz Web Image $19 |
| Pro | + 60 分钟视频 + 4K/60 + 插帧 + 优先队列 | $39/月 | Topaz Photo $39 |
| Studio | + 席位 3 + API 额度 + 商用授权书 | $99/月 | Topaz Studio $79 |

视频额度必须进订阅（它是我们相对 Topaz 的差异点），而不是按积分单卖——否则用户永远算不清一集短剧要多少钱。

### 线 C · B2B：API + 白标（这才是毛利率最高的地方）
把 9 个模型按**行业**重组，而不是按模型名卖：

| 行业包 | 组进去的模型 | 客户 | 计价 |
| --- | --- | --- | --- |
| 电商图片包 | `cutout-fast`、`retouch-quality`、`tryon-quality`、`erase-quality` | 店铺代运营、跨境卖家 | $0.01/张起，量级阶梯 |
| 家装/地产包 | `interior-quality`、`erase-quality` | 家装公司、地产中介 | $0.02/张 |
| 印刷/刺绣包 | `vectorize-fast` | 印花厂、刺绣、LOGO 定制 | $0.03/张 |
| 影楼/证件包 | `pixrestore-s`、`retouch-quality`、`makeup-quality` | 影楼、相馆、婚庆 | $0.05/张 |
| 视频包（上线即开） | 超分、插帧、去噪 | 短剧出海、MCN、老片修复商 | $0.05–0.15/秒或按分钟包 |

API 的商业纪律：**价格 = GPU 成本的 3–5 倍**，永远不低于 Replicate 的 $0.002/张；给承诺用量折扣（$500/月 9 折、$2000/月 8 折）；白标另收平台费 $299/月起（客户自己的域名、自己的品牌，我们只做算力与模型）。

## 4. 获客：按「离钱的距离」排序

1. **先吃已有流量里的任务意图（本周可做）**
   `/visual-enhancer` 28 天 810 次访问、`/download` 5,590 次。前者加「上传→付款→下载」的直达按钮与三个场景入口（老照片、商品图、游戏画面风格化）；后者的访问者不是买家，改成**引导到 Studio 试用**而不是推销积分。
   验收：`/visual-enhancer` → 结果页 → 付款 的点击链路上线后，付款点击 ≥ 10 次/周（当前 0）。
2. **意图分离：给任务词单独的入口（1–2 周）**
   每个行业包一页，标题就是用户在搜的话：`restore old family photo online`、`remove background for shopify 1000 images`、`upscale anime to 4K`、`短剧 4K 修复 插帧 一条龙`。产品站继续吃 DLSS 品牌词，但**任务页的转化目标只有一个：付费或留邮箱**。
   验收：4 个行业页上线后 30 天，各自自然流量 ≥ 100 次、留邮箱 ≥ 10 个。
3. **把 API 摆到开发者面前（2–3 周）**
   现状是官网明说「没有公开开发者 API」。反过来做：`/api` 一页 + 免费 key（100 次）+ 三个语言的 10 行示例 + 明码价目表 + 状态页。开发者渠道的转化率比消费者高一个量级，而且不依赖品牌词。
   验收：上线 30 天注册 key ≥ 30 个、有实际调用 ≥ 10 个、付费 ≥ 1 个。
4. **垂直直销（4–8 周，一个行业一个行业打）**
   短剧出海公司、电商代运营、影楼连锁、手办/3D 打印定制（我们有 imageToLEGO）——每家先免费做 20 张/1 分钟的对照，把「同源、同规格、可复现」的对照给到对方，再报量价。一次签约胜过一千次点击。
5. **证明体系（贯穿全部，最高杠杆）**
   「世界领先」必须变成**第三方可复核的事实**，否则采购方不信、AI 搜索也不引用：
   - `/benchmark` 已有骨架（官方原句 + 我们测了什么/没测什么）。给它加一栏「同源对照」：输入文件 SHA256、缩放方式、输出规格、目视 + 客观指标（LPIPS/PSNR + 局部裁切），脚本可复现；
   - 视频对照按 `docs/VIDEO-UPSCALING-REVIEW-20261120.md` 的规范做（已有三个 SHA256 与同帧裁切纪律），等 Topaz 授权确认后公开；
   - 3D/纹理上线时，同一套规范直接复用。
   验收：`/benchmark` 上每个优势数字旁边都有来源与核对日（这是我们内容闸门一直在守的规矩），并且页面被 AI 搜索引用（每季度抽查 10 个问句）。
6. **不做的事**：不投付费广告（现在 LTV 未证明，投出去是买亏损）；不在 DLSS 新闻词上加购买按钮（人群不对，毁体验）；不靠降价换量。

## 5. 3D 重建与纹理贴图：别当平台发，按「资产」卖

一个新能力最怕的上市方式，是发一个「3D 重建平台」让用户自己找用途。建议：

- **窄切口起手**：`一张照片/一段环绕视频 → 带纹理的可用模型`，第一批只做三个用途：电商 3D 展示（与现有 `interior-quality`、`tryon-quality` 客户重叠）、手办/3D 打印定制（接 imageToLEGO）、游戏资产参考（接 Studio 风格重绘线）。
- **按资产计价**：$2.9 / 资产（≤50k 面）、$9.9 / 资产（高精度 + 4K 贴图）；B2B 按资产量阶梯 + 白标。
- **包装成「可交付物」**：GLB/FBX + PBR 贴图包 + 一个可在浏览器里转的预览页（这是我们已有的能力，成本低、说服力高）。
- **先做证据再做宣传**：选 10 个真实客户物件，公开「输入照片 + 输出模型 + 面数/贴图规格 + 可下载样例」，比任何形容词都值钱。

## 6. 必须补的 6 个数（现在一个都读不到）

注册数、激活数（第一次成功出图）、首单数、付费留存、ARPU、API 调用与毛利。没有这六个，「包装好不好」只能靠感觉。其中注册/激活读不到的原因是 `.env.local` 的 service account 指向的 Firestore 库是空的——生产项目用的是另一套凭据，这件事要先解决（谁生产凭据谁提供，我只做只读接入）。

## 7. 30 / 60 / 90 天

**0–30 天（目标：第一笔真实收入）**
- 线 A 的「视频修复·短片段 $9.9」手动交付页 + 老照片 $4.9 两页上线；只对已有名单（`/download` 申请者、`/topaz-free` 邮箱）发一次。
- `/visual-enhancer` 加付费直达与三个场景入口。
- 公开 API 的最小版本：100 次免费 key、价目表、三条示例。
- 验收：真实付款 ≥ 5 笔（合计 ≥ $30）、API key ≥ 20 个。

**31–60 天（目标：可重复的获客）**
- 4 个行业包落地页 + 各自价目；白标方案一页。
- 视频超分/插帧内测转付费（限额、预付、退款条款写清），配额卖给 3–5 家短剧/MCN。
- `/benchmark` 加同源对照栏（图像首做，视频等授权）。
- 验收：付费用户 ≥ 25、MRR ≥ $300、至少 2 家 B2B 在跑量。

**61–90 天（目标：结构成立）**
- 按行业拆出独立品牌站（任务词、独立域名），主站退回「品牌 + 证据 + 开发者」。
- 3D 资产包试售（10 个真实物件做样例）。
- 验收：付费用户 ≥ 80、MRR ≥ $1,200，其中 B2B 占比 ≥ 40%。

## 8. 需要王胜拍板的三件事

1. **先卖什么**：线 A 的两个一次性 SKU（我可以本周做完页面与交付流程）——同意就开工。
2. **公开 API 开不开**：现在官网写着「没有公开 API」。开，就意味着要定免费额度、价目表和滥用防护；这条线毛利最高，也最需要你的定价意见。
3. **视频内测转付费的边界**：谁可以买、卖多少分钟、失败怎么退。Waffo 目前只接订阅，一次性付款（线 A）需要用同一套回调，Codex 那边加一个 SKU 即可。
