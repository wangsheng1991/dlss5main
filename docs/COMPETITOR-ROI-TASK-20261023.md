# 工单：GSC × 竞品 SERP 深挖 —— 找出抢排名的 1–2 件事（2026-10-23）

王胜原话要点：「结合 GSC 后台，分析搜索关键词、以及关键词对应的**还排在我们前面**的网站；他们为什么做得好、为什么能占住这个词；目标是从里挑出 **1–2 个 ROI 最高**的事，然后直接做。做软件也没关系，我们有自有模型/管线，可以自己写。」

→ 这一轮要产出的是**判断 + 方案**，不是又一份数据表。方案要具体到「我们做什么、凭什么能抢到、第一步怎么落地」。

## 0 边界

- **本轮不改站点代码、不部署**（等王胜从 1–2 个方案里点选后再实施）。
- 数字只写页面/接口上看到的原文；抓不到的写「抓不到」。竞品流量我们**没有**第三方数据，不要编访问量，也不要拿 SimilarWeb 猜。
- 抓 SERP 要记下：查询原文、地区/语言、抓取时间、是否出现 AI Overview / PAA / 视频 / 图片 / 购物等特性。
- 需要联网走 `http://127.0.0.1:1082`；SERP 用系统 Chrome 抓（curl 会被拦），现成脚本在
  `/Users/wangsheng/.penguin/data/default_project/agents/default_agent/shared_env/seo/serp-batch.mjs`（Playwright + 系统 Chrome，写 `/tmp/serp/*.html`）与 `parse-serp.py`（把 DOM 解析成排名列表）。**复制一份到自己目录再改 QUERIES，不要改共享脚本**。

## 1 先定「值得抢的词」

从 `docs/GSC-ROI-ANALYSIS-20261022.md`（尤其第 3 节关键词簇、第 5 节页面榜）里取候选，规则：

- 最近 28 天**展示 ≥ 150** 且**平均排名 4–15**（离前三一步之遥），或 CTR 明显低于同位置常识（展示多、点击≈0）。
- 按「展示 × 假设可提升的 CTR」粗排，取前 15 个查询；按意图合并成 **5–8 组**（同义词并组，不要一个词一组）。
- 每组写：查询（含变体）、我们当前展示/点击/CTR/排名、落点页面、所属簇。

## 2 抓竞品 SERP（每组一条主查询）

- 每组至少抓 1 条主查询的真实 SERP（US/en；中文词组再抓一次 zh-CN，地区设中国或新加坡，写明设的哪个）。
- 记录前 5 个自然结果：URL、域名、标题、描述、页面类型（工具页 / 长文 / 论坛 UGC / 厂商官网 / 聚合站）、是否有站内工具、是否带视频或图片包。
- 记录 SERP 特性：AI Overview 有没有、PAA 问的是什么（列 3–5 条原问）、有没有 video/images/shopping。

## 3 解剖前 3 名竞品页（每家只取关键事实）

对每组前 3 名里的**域名级对手**（同一域名只解剖一次），抓页面本身并记录：

- 页面类型与核心承诺（是不是上来就能用的工具？要不要登录/付费？）
- 内容体量：正文字数（粗量级即可）、是否有对照表、是否有逐条来源
- 更新痕迹：页面上的日期 / 结构化数据里的 dateModified
- 结构化数据：有哪些 `@type`（SoftwareApplication / FAQPage / HowTo / Review / VideoObject…）
- 媒体：图片数、视频数、截图是不是真实界面
- 站内结构：有没有指向同主题的其它页（内链密度）、有没有 /tools 目录
- 品牌与背书：是不是厂商、有没有 GitHub 仓库、有没有真实用户评论

## 4 归因：他们凭什么占住这个词（这是重点）

每组写 2–3 条**可检验**的判断，不要空话。例如：
- 「他是**真工具**，落地即可上传跑图，而我们是介绍页 → 用户点进去就得到结果，跳出率低」
- 「他覆盖了 PAA 的 4 个子问题，我们只答了 1 个」
- 「他的 title 直接是这个查询的完整短语，我们的 title 是品牌句式」
每条后面写：我们能复制吗（能/不能/部分），复制成本大概多少。

## 5 产出 1–2 个「该做的事」

**只提 1–2 个**，宁少勿多。每个方案写：

1. 名字与一句话
2. 抢哪个词/哪组词（附我们的当前数字）
3. 为什么能抢到（对着第 4 节的归因，说清我们比他们多的那一点）
4. 具体做什么：页面改造 / 新建工具页 / 自建小工具（可以用我们的 flux-klein 等自有管线；若要做软件，写清输入输出、要不要登录、跑一次多久、算力放哪）
5. 最小可交付（MVP）：第一版只做什么，几天能上线（写「估」）
6. 预期：用我们的 GSC 展示 × 目标 CTR 算点击增量，**写清公式**；算不出就写「无法量化」
7. 验收：多少天后看哪个数到多少；失败长什么样
8. 风险：会不会踩「假称官方/承诺 APK/无来源倍数」这些红线

最后给一句**推荐**：如果只能做一件，做哪件、为什么。
