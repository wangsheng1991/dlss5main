## 4. 这笔账里哪些是实测、哪些是假设

- **实测**：全站点击 / 展示 / CTR / 位次；13 个词族逐词的展示、点击、位次；CTR 分段曲线；`/visual-enhancer` 与 `dlss 5 apk` 建页前后的展示变化。
- **假设**：每个词族"拉住之后"的位次和展示放大系数（第 3 节表格给全了参数），以及截断补偿到 2 倍的上限。
- **不知道的**：这 13 个词的**真实搜索需求总量**。三个原因：(1) GSC 查询表只给约 Top 1000 行，本次可见行覆盖 1,062 / 2,736 点击、13,550 / 29,600 展示，**只占 39% 点击、46% 展示**；(2) 匿名查询不逐词显示；(3) 长尾被折叠。所以"0 行"只代表"在我们的可见样本里没有"，不代表没有需求。
- **不做的事**：不引用任何第三方搜索量估算当结论；不把匿名查询推算成具体词；不用 CTR 行业均值代替本站实测。
