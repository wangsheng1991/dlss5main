# 阶段 1：离线视频换脸管线

这套脚本只用于 Linux + NVIDIA CUDA GPU 上的离线短视频换脸验证：5–30 秒、正脸或半侧、镜头相对稳定。它不包含全身角色替换或实时换脸，也不应对这些能力作出承诺。

仅处理本人或已取得明确授权的人脸和视频，并在使用前核对 FaceFusion 与实际下载模型的许可是否符合用途。

## 三步跑通

在此目录执行：

```bash
./check-env.py
./setup.sh
./run.sh --source /path/to/face.jpg --target /path/to/clip.mp4 --output /path/to/result.mp4
```

`check-env.py` 总会输出 JSON；无法读取的项目为 `null`，原因记录在 `error`。`setup.sh` 克隆官方 FaceFusion 仓库 `https://github.com/facefusion/facefusion.git`，在 `facefusion/.venv` 创建隔离环境，并执行官方安装入口 `python install.py cuda@12` 或 `python install.py cuda@13`（脚本按探测到的 CUDA 选择；可用 `FACEFUSION_ONNXRUNTIME` 覆盖）。它不会使用 `sudo` 或修改系统 Python。首次运行 FaceFusion 可能下载模型，须保证 GPU 机器能访问相应资源。

若 FaceFusion 放在其他位置，可在两条脚本前设置 `FACEFUSION_DIR=/path/to/facefusion`。安装脚本会保留已有 clone 的版本，不会自行更新。

## 输入规格

- 源图：一张清晰正脸，脸部至少约 100 像素；避免浓重滤镜、强阴影、遮挡和多人。
- 目标：5–30 秒视频，人物正脸或半侧，镜头相对稳定；单人最佳，多人时必须主次分明。
- 输出：`--output` 必须以 `.mp4` 结尾；脚本请求 FaceFusion 用 H.264 (`libx264`) 编码。

显存是否足够、实际耗时和画面可接受程度均待目标 GPU 与具体素材实测。`setup.sh` 发现最大 GPU 总显存低于 4 GiB 时只会警告，仍由操作者决定是否继续。

## 验收

逐帧或慢放检查以下三项，而不只看一张截图：

1. 同一人物在连续帧中是否仍被稳定地替换为同一张脸，是否有跳变或漂移。
2. 在可接受的正脸、半侧范围内是否自然；记录开始变形、漏换或误换的角度，作为这条素材的极限。
3. 脸部边缘、眼睛、嘴部和遮挡交界是否出现明显发糊、闪烁、块状伪影或不合光照的贴片感。

没有 GPU 实测前，不记录成功率、处理时长或任何“始终像同一个人”的结论。

## 常见失败与判断

| 情况 | 怎么判断 | 处理边界 |
| --- | --- | --- |
| 角度过大 | 侧脸、低头或转头时出现漏换、五官拉伸、脸形漂移 | 裁到正脸/半侧稳定片段；若关键镜头不能裁，不把该片段列为可交付。 |
| 遮挡 | 手、武器、头发或护甲经过脸部时，遮挡物边缘被错误替换或五官穿透 | 逐帧定位遮挡区；能剪则剪，不能剪则标为当前管线限制。 |
| 运动模糊 | 快速动作或镜头摇动处，五官糊成块、边缘闪烁或前后帧不连贯 | 改用更稳定、清晰的源片段；是否改善须实测，不能预先承诺。 |
| 多人同框 | 换错对象、多个脸被替换，或人物进出画面后选择对象变化 | 只用单人镜头；主次不能明确时，不把自动结果视为合格。 |

游戏画面中的风格化角色、强彩色光和写实源人脸还可能造成明显画风错配；这属于素材与审美风险，应在交付前用目标镜头审看。
